# Qualification scope

Run `python3 -m unittest discover -v` for repeatable local qualification. Each test creates private temporary state. The repository workflow runs the same suite on Linux and macOS and executes a separate real etcd quorum-loss lab. Read the run for a particular commit to determine which platform checks passed.

| Behavior | Evidence exercised |
| --- | --- |
| Goal to accepted outcome | A real process uses a leased capability, stores a knowledge revision, survives reopening SQLite, and requires separate acceptance evidence. |
| Plan correctness | Repeated mutation identity, stale revision, unmet dependency, cycle rejection and readiness. |
| Reusable BPMN | Import an actual BPMN XML user task, submit an answer, preserve captured child definitions, execute a parallel join and reject conflicting branch writes. |
| Programs and provider changes | Compile nested routines, preserve per-run intermediate readings, execute both branches of a radio survey, extract a parameterized routine from history, invoke it as a capability and migrate a running definition at a safe point. |
| External effects | A subprocess adapter writes an effect, loses its response, restarts against its ledger, and reports the prior result exactly once. An uncertain action blocks release, and a stale owner cannot confirm a superseded fence. |
| Construction | Stage a Python adapter by content digest, run its probes, install a manifest entry and invoke the published contract. |
| First contact | Unknown key cannot enroll itself. Independent fingerprint approval, proof of possession, signed request binding and revocation are checked. |
| Offline collaboration | Two independent SQLite nodes sign and exchange pages, retain concurrent same-parent changes, reject tampering and suppress duplicate imports. A delegated child runs offline, returns once, and moves its original task to review. |
| Resource pressure | A dependency shared by critical work is counted once; twelve, six and three unit budgets produce the expected modes and unmet minima. |
| Operator surface | Real HTTP listener, UI response, authentication, MCP invocation, durable subscription, inbox and backup/restore hold. |
| Shared controller failure | The CI cluster test uses real etcd members, stops the elected leader, commits on a majority, removes quorum, and confirms local work and subsequent catch-up. |

The shipped scope is the executable profile documented in the runtime and deployment guides. Radio and actuator test fixtures establish contract and dispatch behavior. Hardware-specific measurement, driver compatibility, operating budgets, network conditions and physical safety need qualification on each provider. A device with several independent control paths requires a fence enforced at their common resource. A software-only adapter cannot enforce control over out-of-band users of the same hardware.
